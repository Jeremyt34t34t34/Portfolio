Educational capstone · Python · RAG

Biomedical Dataset Discovery Assistant

Find public biomedical datasets through normalized GDC and cBioPortal metadata, with source evidence and explicit limitations.

  • Constrained keyword retrieval with TF-IDF cosine reranking and optional live OpenAI RAG.
  • Streamlit reviewer UI, HTTP API, and a deterministic tool workflow with an inspectable trace.
  • Feedback collection and retrieval, answer, and claim evaluation workflows.

Study-level metadata; variant-positive patient counts remain unverified. The local workflow uses fixed tool steps. This capstone is not a production cloud deployment.
